
# 📘 Assignment: Hangman Game Challenge

## 🎯 Objective

In this assignment, you will build a playable Hangman game in Python. You will practice using strings, loops, conditionals, and user input to create an interactive program.

## 📝 Tasks

### 🛠️ Build The Game Setup

#### Description
Create the core setup for your Hangman game, including the word list, random word selection, and starting game state.

#### Requirements
Completed program should:

- Store at least 5 possible words in a predefined list.
- Randomly select one word as the hidden word when the game starts.
- Display the hidden word as underscores (for example: `_ _ _ _`).
- Set a fixed number of incorrect guesses allowed (for example: 6).


### 🛠️ Implement Guessing And Game Flow

#### Description
Add the gameplay loop so the player can guess letters, see progress, and receive a final win or lose message.

#### Requirements
Completed program should:

- Ask the player for one letter guess at a time.
- Reveal correctly guessed letters in all matching positions.
- Reduce the remaining attempts only when the guess is incorrect.
- End with a win message when the full word is guessed.
- End with a lose message when no attempts remain and show the correct word.
